# 🍽️ G6-Foodnow

> Ett receptprojekt byggt av Grupp 6 – FE25-KYH  
> **Backend:** Strapi CMS **Frontend:** React + Vite

---

## 📋 Om projektet

FoodNow är en receptapplikation där användare kan utforska, söka och hantera recept. Projektet är ett skolprojekt inom kursen Javascript 3 på KYH.

---

## 🛠️ Teknikstack

| Del       | Teknik                        | Version  |
|-----------|-------------------------------|----------|
| Frontend  | React + Vite                  | React 19 |
| Backend   | Strapi CMS                    | v5.45.0  |
| Databas   | SQLite (via better-sqlite3)   | –        |
| Styling   | CSS / Styled Components       | –        |

---

## 🚀 Kom igång

### Förutsättningar

- **Node.js** `>=20.0.0`
- **npm** `>=6.0.0`

---

### 1. Klona projektet

```bash
git clone https://github.com/Maizer89/G6-Foodnow.git
cd G6-Foodnow
```

---

### 2. Starta Backend (Strapi)

```bash
cd Backend
npm install
npm run develop
```

Strapi körs på: [http://localhost:1337](http://localhost:1337)  
Admin-panel: [http://localhost:1337/admin](http://localhost:1337/admin)


| Fält     | Värde              |
|----------|--------------------|
| E-post   | admin@admin.com    |
| Lösenord | 987654321aA        |

---

### 3. Starta Frontend (React)

Öppna ett **nytt terminalfönster**:

```bash
cd Frontend
npm install
npm run dev
```

React-appen körs på: [http://localhost:5173](http://localhost:5173)
